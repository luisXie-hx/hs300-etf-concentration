# 沪深300ETF 头部集中度监测

> **在线版**：https://luisxie-hx.github.io/hs300-etf-concentration/
> 手机可直接打开，已适配移动端布局。

追踪「头部 4 只沪深300ETF 份额 ÷ 全部沪深300ETF 份额」的比例，用来观察大额资金（国家队）的进出节奏。

打开 `index.html` 即可查看。

## 指标定义

- **分子**：华泰柏瑞 510300、易方达 510310、华夏 510330、嘉实 159919 四只的份额合计
- **分母**：全部跟踪沪深300指数的被动 ETF 份额合计（25 只，已剔除红利/价值/成长/ESG/自由现金流/指数增强等变体）
- 用**份额**而非规模，避免净值涨跌干扰，干净反映申购赎回

## 每日更新

**自动（已配置）**：WorkBuddy 定时任务「沪深300ETF份额每日更新」，每天 **21:00 / 23:00** 自动运行并回报结果。需要 WorkBuddy 处于运行状态。

**更可靠的方式（不依赖任何 App）**：在终端里执行一次

```bash
cd "/Users/luis/WorkBuddy AI/金融" && ./install-schedule.sh
```

装好后只要电脑开机，每晚 21:00 和 23:00 各跑一次（第二次补漏），日志在 `~/Library/Logs/hs300etf-update.log`。

> 卸载：`./install-schedule.sh remove`

**手动**：

```bash
./update.sh
```

建议在交易日 **15:30 之后**运行（收盘后深市快照才会写入历史，避免盘中值污染序列）。

流程：抓沪市日频份额 → 抓深市季报 → 抓当日快照 → 合并计算 → 导出前端数据。日常增量约 30 秒。

## 页面功能

- **区间滑块**：主图和份额结构图底部各有一条可拖动的区间滑块，拖两端把手可选任意区间；图表内滚轮缩放、横向拖动平移，两图联动。上方 `全部 / 近三年 / 近一年 / 近三月` 是快捷预设，手动拖动后会按实际区间自动匹配。
- **口径切换**：`全市场口径`（25 只合计）与 `仅沪市口径`（19 只，纯交易所日频数据）。
- **纵轴自适应**：选定区间后纵轴按区间内最高/最低自动缩放，刻度取整到 1/2/2.5/5 步长。

## 部署到 GitHub（免费、7×24 自动更新）

本地仓库已初始化好，推送即可。

**1. 在 GitHub 新建一个仓库**（Public / Private 都行），然后：

```bash
cd "/Users/luis/WorkBuddy AI/金融"
git remote add origin git@github.com:<你的用户名>/<仓库名>.git
git push -u origin main
```

**2. 打开仓库 Settings → Pages**

- Source 选 **Deploy from a branch**
- Branch 选 **main**，目录选 **/(root)**，保存

几分钟后访问 `https://<用户名>.github.io/<仓库名>/`。

**3. 之后全自动**

`.github/workflows/update.yml` 每天 **北京时间 21:00 / 23:00** 自动：

```
抓沪市份额 → 抓深市季报 → 抓当日快照 → 重建数据集 → 提交 data/ 和 data.js → Pages 自动重新发布
```

也可以在仓库的 **Actions** 页面点 `Run workflow` 手动触发一次，先验证能不能抓到数据。

### 需要注意

- **Actions 用的是境外机房 IP**。跑完看日志里这三行是否正常：
  - `待抓取 N 天（已跳过 100 个非交易日）`
  - `DONE days= 1245  empty= 100`
  - `snapshot 6 只（深市）`
  
  如果 `snapshot 0 只` 或 `FAIL`，说明东财对机房 IP 有限流——沪市数据仍会正常更新，深市会退回季报插值，不影响主指标趋势。
- **GitHub Pages 国内访问不稳定**。想要快且免备案，可以再把这个仓库接到 Cloudflare Pages（免费，自动跟随每次 push 部署）。
- Actions 定时任务在高峰期可能延迟几分钟到半小时，不影响日频数据。
- 仓库里 `data/` 约 10MB，随年份增长约每年 +2MB，GitHub 单文件上限 100MB，短期内无需担心。

## 数据口径

| 市场 | 来源 | 频率 |
|---|---|---|
| 沪市（19 只） | 上交所每日披露 ETF 总份额（TOT_VOL） | 真实日频 |
| 深市（6 只） | 基金季报「期末总份额」为锚点，锚点间按交易日线性插值 | 季度锚点 + 插值 |

- 沪市数据与基金季报期末份额**完全对得上**（已交叉验证：510300 在 2026-09-30 两者均为 241.20 亿份）
- 深市交易所不提供历史日频。`update.sh` 每天收盘后会把深市快照写入 `data/sz_snapshots.json`，**随着时间推移深市数据会逐步由插值转为真实日频**
- 深市约占全市场 12%–15%，对占比曲线影响在 1 个百分点以内

## 口径提醒

份额数据只能看到「有多少份额」，看不到「谁持有」。头部 4 只长期是中央汇金等机构的主要配置标的，其份额的大幅集中与分散与国家队操作节奏高度吻合，但**份额变化本身不能直接证明交易主体身份**，也可能来自保险、理财、量化等其他大额资金的申赎。
